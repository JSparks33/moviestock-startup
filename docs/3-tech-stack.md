# Tech Stack & Hosting Strategy
## Defined Tech Stack
* 'React (with React Native / Responsive Web)': Used to build an interactive, responsive front-end user interface that delivers seamless cross-platform compatibility across desktop, mobile devices, smart TVs, and game console browsers.
* 'Node.js & Express (with Streaming Metadata APIs)': Used for the back-end aggregation layer to power the Global Unified Search Catalog, unifying worldwide movies, TV shows, and subscription pricing data into a single portal.
* 'Firebase (Authentication & Firestore)': Used for user authentication, subscription bundle management, and real-time cloud syncing so watch progress carries over across devices without extra data overhead.
## Hosting & Deployment Strategy
The MovieStock web application will be hosted on **Vercel** (connected directly to our GitHub repository for continuous deployment) so end-users can immediately access the portal via any desktop, mobile smart TV, or console web browser.
